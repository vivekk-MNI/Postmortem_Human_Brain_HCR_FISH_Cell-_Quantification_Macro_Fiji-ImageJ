# Postmortem-HCR-FISH-Cell-Quantification-Macro-Fiji-ImageJ-
This repository provides a custom ImageJ macro to batch-process and quantify HCR FISH-labeled cells in frozen postmortem human cortical tissue, incorporating nuclear proximity filtering and layer-specific analysis. The macro supports flexible processing of two independent gene panels:  Panel 1: SST / Reelin  Panel 2: VIP / CCK
